# CSS Classes Reference for Printing

This file exists to populate the dropdown suggestions for the `cssclasses` property in your Obsidian vault. Because Obsidian aggregates and indexes all properties in the vault, having these values declared here ensures they appear in the autocompletion dropdown menu when you edit the `cssclasses` property on any note.

### Available Printing Toggles:
*   `print-minimal` — **Worksheet Mode**. Hides all theory summaries and collapsible derivations, leaving only problem statements and workspaces.
*   `print-solutions` — **Answer Key Mode**. Automatically expands and prints all solutions.
