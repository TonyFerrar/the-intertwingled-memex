# Session 2 - Vectors in 2D & 3D

## Session Overview
Vectors are the fundamental building blocks for modeling the physical world, acting not just as abstract arrows but as the essential language for quantifying how things move and interact in space. In engineering, you will move beyond simple scalar values to define **quantities that possess both magnitude and direction**—like the tension in a bridge cable, the velocity of airflow over a wing, or the magnetic field in a stator.

Whether in 2D (planar motion) or 3D (spatial structures), we express these vectors algebraically using components:

$$\mathbf{v} = \langle v_x, v_y, v_z \rangle \quad \text{or} \quad \mathbf{v} = v_x\mathbf{i} + v_y\mathbf{j} + v_z\mathbf{k}$$

This allows us to break down complex, multi-dimensional real-world problems into manageable equations. Mastering vector operations now is crucial because they provide the computational framework you will use to analyze stress, design control systems, and simulate dynamics in nearly every subsequent engineering course.
