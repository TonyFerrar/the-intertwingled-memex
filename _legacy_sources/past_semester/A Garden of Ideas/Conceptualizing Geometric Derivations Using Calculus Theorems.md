
# Conceptualizing Geometric Derivations Using Calculus Theorems

Beyond rote calculation, this course emphasize **modeling practices**—understanding _why_ these formulas work through the limiting process of Riemann sums. Key sub-skills include:

- **Approximation:** Using the distance formula between points ($P_i−1​$,$P_i​$) to approximate curve segments.
- **Applying Theorems:** Utilizing the **Mean Value Theorem** to relate the slope of a secant line to a derivative ($f'(c_i​)$) and the **Intermediate Value Theorem** to find average function values for surface area approximations.
- **Limiting Processes:** Recognizing how an infinite sum of straight segments or "cone frustums" becomes a definite integral as the number of sub-intervals approaches infinity.
