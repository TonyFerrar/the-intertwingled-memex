# Applying the Trapezoidal Rule

This skill requires using **trapezoids** to follow the curve more closely than linear rectangles. Key components of this skill include:

- Utilizing the specific weighting formula where the **end points $(y_0​, y_n)$ are weighted by 1 and the interior points are weighted by 2.**
- Calculating the approximation $T(n)$ by multiplying the weighted sum of function values by $\frac{\Delta x}{2}$.
- Recognizing that this method uses line segments to approximate the region under a curve.
