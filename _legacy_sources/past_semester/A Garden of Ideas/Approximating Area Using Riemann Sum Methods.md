
# Approximating Area Using Riemann Sum Methods

The primary procedural skill explored is the ability to **approximate the area under a curve** by dividing an interval [a,b] into n subintervals of equal width, denoted as Δx or w. Students are taught to calculate the height of rectangles using three distinct techniques:

• **Left Hand Method (LHS):** Evaluating the function at the left-hand endpoint of each subinterval.

• **Right Hand Method (RHS):** Evaluating the function at the right-hand endpoint of each subinterval.

• **Midpoint Rule:** Evaluating the function at the center point of each subinterval to potentially increase accuracy.
