# What is a Transferrable Skills Portfolio?
We frequently run into an issue in which you take a math course, and then go a year or longer before seeing a certain skill in a future engineering course. **By then, many students have forgotten.** The idea here is to **_create a portfolio of key skills_** - a write up of the skill, key formulas, a worked example, and a list of engineering applications that you’re likely to encounter in future courses. Think of this as a “math rescue kit” that students can keep and use later.

## How Does This Work?
Each Unit of the course will be accompanied by a list of Essential Skills - those skills that are most fundamental, and most useful, to success in future courses and careers. Your task will be to create a brief writeup of each skill, giving you a toolkit that you can employ in future courses. Each Unit's write ups will be due with the exam. For example, in a course with 2 midterms and a final, you'd have 3 due dates (one at each exam).

### For each skill:
- 1 paragraph summary of the concept
- Key formulas, neatly written and organized with all variables defined
- List of major-relevant engineering applications
	- Research by talking to faculty, students, or use print/online resources
	- Cite your source
- 1 example problem (per case if applicable), solved in "textbook example problem" format
	- Cannot be an example problem copied from a textbook - this must be your original work
	- Suggest using a problem from the homework
- Skills due prior to each exam with no extensions
