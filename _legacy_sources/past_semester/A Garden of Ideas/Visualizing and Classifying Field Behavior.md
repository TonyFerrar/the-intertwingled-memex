# Visualizing and Classifying Field Behavior

 Vector fields can show geometric patterns. These patterns are what allows us to define their behavior. 
### Vector Field Patterns:
- **Radial / Source–Sink:** vectors point directly outward or inward (e.g., $\mathbf{F}=\langle x,y\rangle$).
- **Rotational:** vectors circle around an axis (e.g., $\mathbf{F}=\langle -y,x\rangle$).
- **Saddle / Mixed:** direction changes along different axes.

Recognizing these patterns helps engineers interpret flow, rotation, and stability in physical systems.
