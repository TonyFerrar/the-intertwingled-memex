
# Executing the Midpoint Rule

This skill involves approximating the area under a curve by using **rectangles** where the height of each rectangle is determined by the **midpoint of the subinterval**. To master this skill, one must be able to:

- Determine the subinterval width ($\Delta x$) and identify the midpoint ($c_k$​) for each segment.
- Evaluate the function at these midpoints and sum the results to find $M(n)$.
- Apply the rule to both algebraic functions and data provided in a graphical format.
