
Obsidian uses Markdown for text, and Latex for math.

# Hash tags are used for Headings
This heading has a single hash tag in front of it
## Sub heading
This heading has 2 hash tags in front
### sub sub heading
- 3 hashtags
- dashes make bullets



# Lets do math!
For math, a dollar sign starts and ends it.

Inline math: single dollar signs. $x = 5+2$
Centered separate math: double dollar signs
$$ x = 5+2$$
You can google a cheat sheet for latex math commands/syntax. AI is AWESOME at this too.


# The most powerful tool in Obsidian is the link

Double hard brackets creates a link.

[[Here is a link to a new file]]
- If you click this, it will create a new file.
