# Session 13 - Numerical Integration

## Session Overview
This session explores **numerical integration**, a set of techniques used to approximate **definite integrals** when exact analytical solutions are impossible to find. Three primary strategies are introduced: the **Midpoint Rule**, which uses rectangles centered on subintervals; the **Trapezoidal Rule**, which fits trapezoids to the curve; and **Simpson’s Rule**, which employs parabolic arcs for enhanced accuracy. Each method is supported by **mathematical formulas** and step-by-step examples that demonstrate how to partition intervals and calculate **Riemann sums**. Ultimately, this session is about developing a practical framework for estimating the **net area** under a curve through increasingly sophisticated geometric models.
