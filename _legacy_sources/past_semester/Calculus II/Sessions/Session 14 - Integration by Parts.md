# Session 14 - Integration by Parts

## Session Overview
This session provides a comprehensive introduction to **integration by parts**, a Calculus II technique derived from reversing the [[product rule for derivatives]]. The core formula is **$\int u \, dv = uv - \int v \, du$**. This method should be utilized when standard **u-substitution** or direct integration is insufficient. To assist in selecting the appropriate components for substitution, follow the **ILATE rule** - an acronym prioritizing harder to integrate functions for the variable $u$ and saving the easier to integrate functions for $dv$. Practical applications are demonstrated through examples requiring **repeated integration** and the evaluation of **definite integrals** using the Fundamental Theorem of Calculus. Furthermore, the accompanying **learning activity** offers structured exercises involving logarithmic, exponential, and trigonometric integrands to reinforce these concepts. Ultimately, this session will teach you how to transform complex products into **simpler, manageable integrals**.
