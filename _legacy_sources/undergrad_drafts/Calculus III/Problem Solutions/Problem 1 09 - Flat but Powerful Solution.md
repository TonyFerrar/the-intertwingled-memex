**Problem:** Given a normal vector $\vec{n} = \langle 0, 2, 6 \rangle$ and point $P = (2, 5, 6)$ from which the normal vector starts, find the equation of the plane.

**Solution:**
Using the point-normal form:
$$a(x - x_0) + b(y - y_0) + c(z - z_0) = 0$$
Substitute $a=0, b=2, c=6$ and $(x_0, y_0, z_0) = (2, 5, 6)$:
$$0(x - 2) + 2(y - 5) + 6(z - 6) = 0$$
$$2(y - 5) + 6(z - 6) = 0$$
$$2y - 10 + 6z - 36 = 0$$
$$2y + 6z = 46$$
Simplifying by dividing by 2:
$$y + 3z = 23$$
