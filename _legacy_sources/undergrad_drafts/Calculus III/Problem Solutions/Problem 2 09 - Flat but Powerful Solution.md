**Problem:** Given a normal vector $\vec{n} = \langle 12, -4, 7 \rangle$ and point $P = (0, 7, 4)$ from which the normal vector starts:
1. Find the equation of the plane.
2. Plot the plane using Desmos.

**Solution:**
Using the point-normal form:
$$12(x - 0) - 4(y - 7) + 7(z - 4) = 0$$
$$12x - 4y + 28 + 7z - 28 = 0$$
$$12x - 4y + 7z = 0$$
