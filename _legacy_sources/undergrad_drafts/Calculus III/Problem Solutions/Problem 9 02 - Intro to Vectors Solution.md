## 1. Labeling the Axes (Right-Hand Rule)
To satisfy the standard **right-hand rule** in this isometric perspective:
* The axis pointing **down and to the left** is the **positive x-axis**.
* The axis pointing **horizontal and to the right** is the **positive y-axis**.
* The axis pointing **vertically straight up** is the **positive z-axis**.

---

## 2. Step-by-Step Plotting Guide

### Point $A = (5, -4, 0)$
1. Start at the origin $(0,0,0)$.
2. Move **5 units forward** along the positive x-axis (down-left).
3. Move **4 units backward** parallel to the y-axis (left, opposite to the positive y direction).
4. Because the z-coordinate is `0`, stay on the xy-plane. Mark this point as **$A$**.

### Point $B = (0, 3, 0)$
1. Start at the origin $(0,0,0)$.
2. Move `0` units along the x-axis.
3. Move **3 units to the right** along the positive y-axis.
4. Because the z-coordinate is `0`, mark this point directly on the axis line as **$B$**.

### Point $C = (1, 3, 2)$
1. Start at the origin $(0,0,0)$.
2. Move **1 unit forward** along the positive x-axis (down-left).
3. Move **3 units to the right** parallel to the positive y-axis.
4. Move **2 units straight up** parallel to the vertical z-axis. Mark this final position as **$C$**.
