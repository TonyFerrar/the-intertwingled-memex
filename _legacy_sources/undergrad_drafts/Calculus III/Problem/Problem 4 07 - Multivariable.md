Given the functions:
1. $f(x,y,z) = x^2 + y^2 - z$
2. $g(x,y,z) = \frac{1}{x^2 + y^2 + z^2 - 9}$
3. $h(x,y,z) = \sqrt{25 - (x^2 + y^2 + z^2)}$
4. $k(x,y,z) = \cos(x-y+z)$
5. $m(x,y,z) = \ln(x+2y+3z)$

* **Task 1:** Find the domain and range of each function
* **Task 2:** Evaluate $f(1,2,3)$, $g(2,1,2)$, $h(3,4,0)$, $k(0,0,\pi)$, and $m(1,1,1)$
