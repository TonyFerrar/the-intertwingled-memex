Given the functions:
1. $f(x,y,z) = x^2 + y^2 + z^2$
2. $g(x,y,z) = \frac{1}{x^2 + y^2 + z^2 - 1}$
3. $h(x,y,z) = \sqrt{9 - x^2 - y^2 - z^2}$
4. $k(x,y,z) = \sin(x+y+z)$
5. $m(x,y,z) = \ln(x+y+z)$

* **Task 1:** Find the domain and range of each function
* **Task 2:** Evaluate $f(1,2,2)$, $g(1,0,0)$, $h(2,1,2)$, $k\left(0,0,\frac{\pi}{2}\right)$, and $m(1,1,1)$
