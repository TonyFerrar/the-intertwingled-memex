3D Vector Addition**

Given the following two three-dimensional vectors:

$$\vec{u} = 2\hat{i} - \hat{j} + 3\hat{k}$$

$$\vec{v} = -\hat{i} + 4\hat{j} - 2\hat{k}$$

- **a)** Find the resultant vector sum $\vec{u} + \vec{v}$.
    
- **b)** Calculate the total magnitude of the combined vector $|\vec{u} + \vec{v}|$.
