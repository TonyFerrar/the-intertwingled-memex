**Problem 2: Cell Freezing & Absolute References**
You are designing a sheet to calculate the volume of a cylinder, given by $V = \pi r^2 h$. The radius is a fixed constant, $r = 5\text{ cm}$, stored in cell `B1`. A list of varying heights ($h$) is provided in column A, from cell `A4` down to `A24`. 
1. Write the formula for cell `B4` to compute the volume for the first height in `A4`.
2. Explain what would go wrong if you used Autofill down column B without using the `$` anchor symbol. How does adding the `$` fix this problem?
