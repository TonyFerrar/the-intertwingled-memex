**Problem 7: Representing Linear Systems in Matrix Form**
Consider the following system of linear equations:
$$\begin{aligned}
4A - 2B + C &= 11 \\
-A + 5B - 3C &= -8 \\
2A + B + 6C &= 7
\end{aligned}$$
1. Rewrite this system in the standard matrix form $[A][X] = [B]$.
2. Write down the matrix algebra expression that isolates the unknown vector $[X]$ utilizing the inverse matrix $[A]^{-1}$.
