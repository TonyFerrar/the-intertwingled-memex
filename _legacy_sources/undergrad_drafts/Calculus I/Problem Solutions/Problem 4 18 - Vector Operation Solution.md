### **Solution to Problem 4**

Here is the step-by-step solution for adding three-dimensional vectors and finding their resultant magnitude.

#### **Part a) Find the Resultant Vector Sum $\vec{u} + \vec{v}$**

To add vectors in three dimensions, simply add their corresponding scalar components ($\hat{i}$, $\hat{j}$, and $\hat{k}$) together.

Given vectors:

$$\vec{u} = 2\hat{i} - \hat{j} + 3\hat{k}$$

$$\vec{v} = -\hat{i} + 4\hat{j} - 2\hat{k}$$

Group the components together:

$$\vec{u} + \vec{v} = (2 + (-1))\hat{i} + (-1 + 4)\hat{j} + (3 + (-2))\hat{k}$$

$$\vec{u} + \vec{v} = (2 - 1)\hat{i} + (-1 + 4)\hat{j} + (3 - 2)\hat{k}$$

Simplify each component:

$$\vec{u} + \vec{v} = 1\hat{i} + 3\hat{j} + 1\hat{k}$$

Or in standard component form:

$$\vec{u} + \vec{v} = \langle 1, 3, 1 \rangle$$

#### **Part b) Calculate the Total Magnitude $|\vec{u} + \vec{v}|$**

To find the magnitude of a 3D vector $\langle x, y, z \rangle$, apply the 3D version of the magnitude formula:

$$|\vec{u} + \vec{v}| = \sqrt{x^2 + y^2 + z^2}$$

Substitute the components from Part a ($x = 1$, $y = 3$, $z = 1$):

$$|\vec{u} + \vec{v}| = \sqrt{(1)^2 + (3)^2 + (1)^2}$$

$$|\vec{u} + \vec{v}| = \sqrt{1 + 9 + 1}$$

$$|\vec{u} + \vec{v}| = \sqrt{11}$$

Using a decimal approximation:

$$|\vec{u} + \vec{v}| \approx 3.32$$

#### **Final Answers**

- **Vector Sum:** **$\hat{i} + 3\hat{j} + \hat{k}$** (or **$\langle 1, 3, 1 \rangle$**)
    
- **Total Magnitude:** **$\sqrt{11}$** (or **$\approx 3.32$**)
