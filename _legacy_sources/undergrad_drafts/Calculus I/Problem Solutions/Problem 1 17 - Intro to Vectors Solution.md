### Solution to Problem 1: Component Form from Two Points

**Problem Statement:** A vector $\vec{PQ}$ starts at the initial point $P(2, 5)$ and ends at the terminal point $Q(10, 10)$. Find the component form of the vector $\vec{PQ}$ using the unit vectors $\hat{i}$ and $\hat{j}$.

#### Step 1: Understand the Formula

To find the components of a vector connecting an initial point $P(x_1, y_1)$ to a terminal point $Q(x_2, y_2)$, you subtract the coordinates of the starting point from the coordinates of the ending point:

$$\vec{PQ} = (x_2 - x_1)\hat{i} + (y_2 - y_1)\hat{j}$$

Where:

- $\hat{i}$ represents the horizontal unit vector ($x$-direction).
    
- $\hat{j}$ represents the vertical unit vector ($y$-direction).
    

#### Step 2: Identify the Coordinates

From the problem description:

- Initial point $P(x_1, y_1) = (2, 5)$
    
- Terminal point $Q(x_2, y_2) = (10, 10)$
    

#### Step 3: Substitute and Calculate

Substitute the values into the component formula:

$$\vec{PQ} = (10 - 2)\hat{i} + (10 - 5)\hat{j}$$

$$\vec{PQ} = 8\hat{i} + 5\hat{j}$$

#### Final Answer

The component form of the vector is:

$$\vec{PQ} = 8\hat{i} + 5\hat{j}$$

_(Alternatively, written in ordered pair notation: $\langle 8, 5 \rangle$)_
