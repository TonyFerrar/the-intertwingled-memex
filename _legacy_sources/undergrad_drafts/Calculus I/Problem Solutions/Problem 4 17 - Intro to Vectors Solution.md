### Solution to Problem 4: Vector Addition (Head-to-Tail)

**Problem Statement:** You are given two vectors:

$\vec{u} = 3\hat{i} - 2\hat{j}$

$\vec{v} = 1\hat{i} + 4\hat{j}$

Find the resultant vector $\vec{u} + \vec{v}$ in component form.

#### Step 1: Understand the Vector Addition Rule

To add two or more vectors together analytically, you combine like terms. This means you add the horizontal ($\hat{i}$) components together, and you separately add the vertical ($\hat{j}$) components together:

$$\vec{u} + \vec{v} = (u_x + v_x)\hat{i} + (u_y + v_y)\hat{j}$$

Geometrically, this corresponds to the "head-to-tail" method, where the tail of the second vector is placed at the head of the first vector, and the resultant vector points from the very start to the very end.

#### Step 2: Identify the Components

From the given vectors:

- For $\vec{u}$: $u_x = 3$ and $u_y = -2$
    
- For $\vec{v}$: $v_x = 1$ and $v_y = 4$
    

#### Step 3: Substitute and Calculate

Group the $\hat{i}$ components and the $\hat{j}$ components together:

$$\vec{u} + \vec{v} = (3 + 1)\hat{i} + (-2 + 4)\hat{j}$$

$$\vec{u} + \vec{v} = 4\hat{i} + 2\hat{j}$$

#### Final Answer

The resultant vector of the addition is:

$$\vec{u} + \vec{v} = 4\hat{i} + 2\hat{j}$$
