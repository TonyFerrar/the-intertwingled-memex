### **Problem 4 Solution**
* The recurrence function is $x_{n+1} = x_n - \frac{x_n^2 - 5}{2x_n}$.
1.  **First Iteration ($x_1$):** $$x_1 = 2 - \frac{2^2 - 5}{2(2)} = 2 - \frac{-1}{4} = 2 + 0.25 = 2.25$$
2.  **Second Iteration ($x_2$):** $$x_2 = 2.25 - \frac{2.25^2 - 5}{2(2.25)} = 2.25 - \frac{5.0625 - 5}{4.5} = 2.25 - \frac{0.0625}{4.5} \approx 2.23611$$
