### **Solution to Problem 2**

Here is the step-by-step calculation to find the magnitude of the given vector.

#### **Formula**

To find the magnitude (or length) of a 2D vector $\vec{u} = x\hat{i} + y\hat{j}$, we use the distance formula derived from the Pythagorean theorem:

$$|\vec{u}| = \sqrt{x^2 + y^2}$$

#### **Given Vector**

$$\vec{u} = 3\hat{i} - 4\hat{j}$$

- Scalar horizontal component ($x$): $3$
    
- Scalar vertical component ($y$): $-4$
    

#### **Step-by-Step Calculation**

1. **Square the individual components:**
    
    $$x^2 = (3)^2 = 9$$
    
    $$y^2 = (-4)^2 = 16$$
    
2. Sum the squared components together:
    
    $$9 + 16 = 25$$
    
3. Take the square root of the sum:
    
    $$|\vec{u}| = \sqrt{25}$$
    
    $$|\vec{u}| = 5$$
    

#### **Final Answer**

The magnitude of the vector is **$5$**.
