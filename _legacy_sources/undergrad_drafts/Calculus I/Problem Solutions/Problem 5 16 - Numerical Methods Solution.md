### **Problem 5 Solution**
1.  **Linearization:** At $x_0 = 9$, $f(9) = \sqrt{9} = 3$. The derivative is $f'(x) = \frac{1}{2\sqrt{x}}$, so $f'(9) = \frac{1}{2(3)} = \frac{1}{6}$. 
    $$T(x) = f(9) + f'(9)(x - 9) = 3 + \frac{1}{6}(x - 9)$$
2.  **Approximation:** Substitute $x = 9.3$:
    $$T(9.3) = 3 + \frac{1}{6}(9.3 - 9) = 3 + \frac{1}{6}(0.3) = 3 + 0.05 = 3.05$$
