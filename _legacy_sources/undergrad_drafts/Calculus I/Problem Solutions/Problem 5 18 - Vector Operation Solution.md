### **Solution to Problem 5**

Here is the step-by-step solution for the navigation word problem, applying vector components to find the boat's true motion.

#### **Part a) Write Out the Components for Both Velocity Vectors**

Let the standard coordinate system be used where:

- Due **North** is along the positive $y$-axis ($+\hat{j}$).
    
- Due **East** is along the positive $x$-axis ($+\hat{i}$).
    

1. **Boat's Velocity Vector ($\vec{v}_{\text{boat}}$):** The boat travels due north at $12\text{ mph}$.
    
    $$\vec{v}_{\text{boat}} = 0\hat{i} + 12\hat{j} = \langle 0, 12 \rangle$$
    
2. **River Current Velocity Vector ($\vec{v}_{\text{current}}$):** The river current flows due east at $5\text{ mph}$.
    
    $$\vec{v}_{\text{current}} = 5\hat{i} + 0\hat{j} = \langle 5, 0 \rangle$$
    

#### **Part b) Determine the Resultant Speed and Actual Direction**

To find where the boat is actually headed, add the two vectors together to find the resultant velocity vector ($\vec{v}_{\text{resultant}}$):

$$\vec{v}_{\text{resultant}} = \vec{v}_{\text{current}} + \vec{v}_{\text{boat}}$$

$$\vec{v}_{\text{resultant}} = \langle 5, 12 \rangle$$

#### **1. Find the True Speed (Magnitude)**

The actual speed of the boat relative to the ground is the magnitude of this resultant vector:

$$|\vec{v}_{\text{resultant}}| = \sqrt{x^2 + y^2}$$

$$|\vec{v}_{\text{resultant}}| = \sqrt{5^2 + 12^2}$$

$$|\vec{v}_{\text{resultant}}| = \sqrt{25 + 144}$$

$$|\vec{v}_{\text{resultant}}| = \sqrt{169} = 13\text{ mph}$$

#### **2. Find the Actual Direction (Angle)**

To find the angle $\theta$ relative to due East (the positive $x$-axis), use the tangent trigonometric function:

$$\tan\theta = \frac{\text{Opposite}}{\text{Adjacent}} = \frac{y}{x}$$

$$\tan\theta = \frac{12}{5}$$

$$\theta = \tan^{-1}\left(\frac{12}{5}\right)$$

$$\theta \approx 67.38^\circ$$

Alternatively, if you measure the angle relative to due North (how far the current pushes it off course east of north):

$$\theta_{\text{off-course}} = \tan^{-1}\left(\frac{5}{12}\right) \approx 22.62^\circ\text{ East of North}$$

#### **Final Answers**

- **Velocity Components:** $\vec{v}_{\text{boat}} = \langle 0, 12 \rangle$ and $\vec{v}_{\text{current}} = \langle 5, 0 \rangle$
    
- **Resultant Speed:** **$13\text{ mph}$**
    
- **Actual Direction:** **$67.38^\circ$ north of east** (or **$22.62^\circ$ east of north**)
