### **Solution to Problem 1**

Here is the step-by-step solution for finding the position vector between points $A$ and $B$.

#### **Part a) Vector in terms of $\hat{i}$ and $\hat{j}$**

To find the position vector $\vec{AB}$ from an initial point $A(A_x, A_y)$ to a terminal point $B(B_x, B_y)$, use the formula:

$$\vec{AB} = (B_x - A_x)\hat{i} + (B_y - A_y)\hat{j}$$

Given:

- Initial Point: $A = (2, 5)$
    
- Terminal Point: $B = (-3, -1)$
    

Substitute the coordinates into the formula:

$$\vec{AB} = (-3 - 2)\hat{i} + (-1 - 5)\hat{j}$$

$$\vec{AB} = -5\hat{i} - 6\hat{j}$$

#### **Part b) Component Form**

To write the vector in component form $\langle x, y \rangle$, simply pull the scalar coefficients from the unit vectors:

$$\vec{AB} = \langle -5, -6 \rangle$$
