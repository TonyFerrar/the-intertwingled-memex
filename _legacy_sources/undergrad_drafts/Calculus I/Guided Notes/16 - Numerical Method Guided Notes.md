# Session 16 + Numerical Methods 

## Engineering Application
In engineering, spreadsheet formulas allow for the automated data analysis of massive component tables, such as civil engineers simultaneously testing structural beam deflections under changing load parameters using absolute cell referencing. When governing physics equations become highly non-linear and algebraically impossible to isolate—such as calculating fluid friction factors via the Colebrook equation or modeling gas volumes using the Van der Waals equation—engineers code the Newton-Raphson method into solvers to iteratively converge on precise roots. Furthermore, when these problems scale into complex, interconnected networks like thousands of simultaneous structural truss joints or multi-loop electrical circuits, engineers translate these massive systems into matrix notation ($[A][X]=[B]$) to let computers execute fast matrix inversions ($[X]=[A]^{-1}[B]$), instantly resolving all unknown forces or voltages at once.
