# Active Calculus OER Portal

A custom digital learning reference and interactive Digital Garden for UNLV Calculus courses. Built for mobile-first in-class active learning.

## About this Curriculum

This curriculum implements active learning by structuring class sessions into 3 distinct Skill Blocks, replacing standard lectures with active worked examples, hands-on student practices, and peer discussion. The entire curriculum is structured inside a Zettelkasten Digital Garden, allowing students to explore prerequisite concepts bidirectionally.
